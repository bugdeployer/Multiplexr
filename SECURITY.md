# Security reports

Use GitHub's private vulnerability reporting for this repository. Include the affected version, reproduction steps and the security impact. Do not attach credentials, publisher private keys, user libraries or private media.

Please avoid publishing an exploit in a public issue before a fix is available. Ordinary crashes and layout problems belong in public issues.

The plugin host treats packages as untrusted. A signature identifies a key, not an endorsement. Report sandbox escapes, permission bypasses, credential exposure and incorrect collection access as security issues.

Collection/app locks do not encrypt media stored on the device. External players and readers follow their own access and privacy behavior.
