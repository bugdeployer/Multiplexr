# Changelog

## 0.5.0

First release from this public repository.

- Local collections for video, music, audiobooks, ebooks and comics.
- Built-in playback/readers, progress tracking and library backup/restore.
- Importable themes and signed plugin packages.
- Plugin SDK and theme authoring guides included with source and release archives.
- Android application ID: `com.bugdeployer.multiplexr`.

Earlier private previews are not part of this repository's release history. Export a backup and reconnect folders when moving from the old application ID.
